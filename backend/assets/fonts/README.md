# Bundled fonts

These fonts are embedded into the backend binary for PDF export.

- `NotoSansSC.ttf` — Noto Sans SC, by Google.
  Upstream: https://github.com/notofonts/noto-cjk
- `NotoEmoji.ttf` — Noto Emoji, by Google.
  Upstream: https://github.com/googlefonts/noto-emoji

Both are licensed under the SIL Open Font License, Version 1.1 — see
`OFL.txt` in this directory. When redistributing the fonts (in source or
binary form), keep this license file with them.
